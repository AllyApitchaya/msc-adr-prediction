# msc-adr-prediction

Machine learning for predicting adverse drug reactions (ADRs) from drug molecular features and public pharmacovigilance data.

This repository contains the code for an MSc dissertation submitted to the University of Edinburgh (MSc Data Science, Technology and Innovation).

## Overview

Adverse drug reactions are a major cause of patient harm. This project develops a multimodal machine learning approach to predict drug-ADR associations by combining:

- Molecular graph representations of drugs, encoded with a Graph Attention Network (GAT), from PubChem SMILES strings
- Semantic embeddings of MedDRA preferred terms, encoded with BioBERT
- Pharmacovigilance signals from the FDA Adverse Event Reporting System (FAERS)

As a proof of concept, the study focuses on 15 antidiabetic drugs (ATC class A10) using FAERS data from 2020-2022.

## Data sources

| Source | Description | Access |
|--------|-------------|--------|
| PubChem | Drug molecular structures (SMILES) | Public, CC0 |
| FAERS | Adverse event reports (2020-2022) | Public, FDA |
| SIDER 4.1 | Label-derived side effects, used for external validation | Public |

Raw and processed data files are not included in this repository, due to file size and data redistribution considerations. All data can be regenerated by running the notebooks in order.

## Notebooks

| Notebook | Purpose |
|---|---|
| `00_environment_test.ipynb` | Environment and dependency check |
| `01_data_collection.ipynb` | Data retrieval (PubChem + FAERS) |
| `02_preprocessing.ipynb` | Cleaning, temporal splitting, negative sampling |

## Results

The `results/` directory contains the numerical outputs underlying every table and figure in the dissertation:

| File | Contents |
|---|---|
| `baseline_xgboost_metrics.csv` | XGBoost test-set performance |
| `gnn_test_metrics.csv` | GAT-only test-set performance |
| `multimodal_test_metrics.csv` | Cross-attention fusion test-set performance |
| `ablation_results.csv` | All model configurations (Table 4.1, 4.2) |
| `bootstrap_test.csv` | Significance test for concatenation vs cross-attention |
| `atom_attribution_metformin.csv` | Atom occlusion effects (Table 5.1, Figure 5.1) |
| `interpretability_summary.csv` | Feature separation and occlusion summary |
| `disproportionality_results.csv` | PRR, ROR, IC per drug-ADR pair |
| `sider_*.csv` | SIDER external validation (Tables 5.2, 5.3) |
| `figs_data/` | Frozen test-set predictions and derived tables |

`results/figs_data/crossattn_preds.npz` holds the frozen test-set predictions used to generate all figures and derived tables, so results can be reproduced without retraining.

## Environment

- Python 3.10, Google Colab (NVIDIA Tesla T4)
- `torch`, `torch-geometric`, `rdkit`, `xgboost`, `shap`, `scikit-learn`, `pandas`, `matplotlib`
- `transformers==4.44.2`, BioBERT `dmis-lab/biobert-base-cased-v1.1`
- Random seed 42 across PyTorch, NumPy, and Python `random`

## How to reproduce

The notebooks are designed to run on Google Colab and should be run in numerical order.

1. `01`-`02` assemble and preprocess the dataset.
2. `03`-`06` train the baseline, unimodal, and multimodal models.
3. `07`-`08` produce the interpretability audit and external validation.
4. `09` regenerates every figure and derived table from the stored predictions in `results/figs_data/`, without retraining.

Note that `atom_features()` must remain identical across notebooks 04, 06, and 07 for model checkpoints to load correctly.
